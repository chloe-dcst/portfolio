Création d'une application web sur les AirBnb

HTML/CSS JavaScript/Plotly
durée : 40 heures | groupe : 4 personnes

L'objectif

Créer une application web sur les statistiques des logements AirBnb à Paris en utilisant la technologie Plotly.

La description du projet

Pour réaliser cette application web, nous devions utiliser le framework Plotly de JavaScript et respecter quelques contraintes : un premier onglet (ou zone ou page) avec un ensemble de graphiques et tableaux liés d’informations sur les variables suivantes avec filtres (type de logement (room_type), prix (price), d’autres informations de notre choix qui ont du sens pour un décideur d’AirBnb, si possible carte globale de Paris avec un (petit) point pour chaque logement.), un deuxième onglet (ou zone ou page) avec une carte choroplèthe, pour laquelle on peut choisir la statistique représentée (nombre de logements, prix moyen, part de logement entier) et un troisième onglet, représentant les parts de type de logement par arrondissement de type "small multiples". Nous avons fait les choix de faire une page différente pour chaque onglet. Tout fonctionne correctement mais pour les améliorations nous aurions aimé faire en sorte que, sur la page Analyse des données, quand on choisit un type de logement les graphiques camemberts disparaissent ou au moins celui de gauche parce qu'ils ne sont plus très utiles.

L'évaluation

- Présentation de l'outil développé
- Qualité des commentaires et de la présentation
- utilisation de la technologie Plotly

Les compétences acquises

- Apprendre à utiliser la technologie Plotly

Le bilan personnel

Ce projet m'a permis de découvrir la technologie Plotly et de l'utiliser pour créer des graphiques et des tableaux interactifs.
